# سيبويه — منصة اللغة العربية

تخصيص Flutter لتطبيق TutorLoom الذي اختاره صاحب المشروع، بهوية عربية سوداء وذهبية وعاجية، وصورة المدرس مصطفى عبدالفضيل الشعار. المصدر الأصلي وترخيصه محفوظان، والدخول الأصلي متاح في `student_mobile_app/lib/main_tutorloom.dart`.

**مسار التطبيق الحالي:** `student_mobile_app/lib/main.dart` → `lib/sibawayh/` → Firebase Auth + Firestore.

## وظائف النسخة

- اسم وهاتف وصف وإيميل وكلمة مرور، دخول واستعادة كلمة مرور.
- رسالة WhatsApp للتفعيل والتجديد يرسلها الطالب بنفسه، ولا يُفعَّل بسبب فتح واتساب.
- اشتراك دراسي لمدة 30 يومًا يفتح كل أقسام صف الطالب، وتجديد مبكر يضاف للمتبقي.
- كورسات «طور نفسك» منفصلة بتفعيل ومدد مستقلة.
- سوبر بانل من حساب المالك داخل نفس التطبيق، لإدارة الطلبة والتجديد والإيقاف والصور والألوان والنصوص والصفوف والأقسام والكورسات والمحاضرات والترتيب بالسحب والإخفاء.
- اختبارات وواجبات، أسئلة اختيار/مقالي، ترتيبها، توقيت، محاولة واحدة لكل اختبار مع إعادة فتحها من الإدارة، وإتاحة النتائج بعد التصحيح.
- التصحيح المجاني: افتح ورقة الطالب من حساب المالك؛ درجات الاختيار تُحسب، ودرجات المقالي تضعها، ثم تحفظ وتتيح النتائج. لا توجد Cloud Function لتصحيح لحظي عند التسليم.
- YouTube بمشغّله الرسمي، Google Drive بمعاينته، MP4/HLS وروابط Cloudflare القابلة للتشغيل، مع كود حساب/جلسة وسجل مشاهدة.

**الوصول الفعلي يحتاج إعداد مشروع Firebase مستقل وتفعيل قواعده. APK بدون إعدادات المشروع نسخة معاينة تحمل توضيحًا صريحًا، ولا تسجّل حسابات وهمية.**

## حدود الحماية والتكلفة

- Firebase Auth بالبريد وFirestore ضمن حصص الخطة المجانية؛ لا يستخدم هذا المسار Cloud Functions أو Firebase Storage. الصور الصغيرة تُضغط داخل التطبيق ثم تحفظ في إعدادات Firestore، أو يمكن استخدام رابط HTTPS. البيانات والصور والقراءات محسوبة ضمن الحصص.
- صلاحية المالك في `roles/UID` لا يمكن لأي عميل كتابتها، حتى حساب المالك. تضاف مرة واحدة من Console أو Admin SDK موثوق خارج التطبيق. مفاتيح Service Account وكلمات المرور ممنوعة في GitHub وAPK.
- مصادر الدروس في مستندات منفصلة لا يقرأها الطالب إلا إذا كان اشتراكه ساريًا بحسب وقت خادم Firestore. أسماء الكورسات والمحاضرات وحدها ليست روابط الفيديو.
- مصدر YouTube/Drive العام لا يصبح خاصًا بالتطبيق. لا ضمان لحصر تشغيله داخله، ولا حظر لروابط YouTube المطلوبة. كود الجلسة لهما خارج مساحة الفيديو.
- Cloudflare عبر رابط MP4/HLS قابل للتشغيل. R2/Stream الخاصان وتوقيع روابطهما آليًا يحتاجان خدمة موثوقة إضافية؛ لا يوجد سر توقيع داخل Flutter. هذا المسار لا يدّعي اكتمال ذلك الربط.
- `FLAG_SECURE` في أندرويد، وفحص سماعة متصلة وVPN/Proxy من النظام. لا يثبت أن السماعة في الأذن، ولا يمنع كل اعتراض HTTP Canary أو جهاز root أو كاميرا خارجية.
- العلامة المتحركة فوق فيديوهات MP4/HLS المباشرة وتظل داخل شاشة المشغّل الموسعة. ليست علامة جنائية مشفرة مقاومة للإزالة.
- الاشتراك الأساسي مفروض بقواعد الخادم؛ مصدر عام نُسخ سابقًا لا يمكن سحبه بتلك القواعد. مراقبة انتهاء الاشتراك داخل المشغّل تستخدم وقت جلسة محفوظًا على الخادم وعدّادًا أثناء المشاهدة.
- الصور داخل التطبيق تتغير عن بعد، وأيقونة نظام الهاتف تحتاج بناء إصدار جديد. الصور المحدّثة لا تغير ملف الأيقونة المثبت سحريًا.
- حساب الطالب يرتبط بأول جهاز Android يسجل منه بمعرّف جهاز مجزأ، ويُرفض تسجيله من جهاز ثانٍ. المالك وحده يستطيع فك الربط من السوبر بانل عند تغيير الهاتف. هذا قفل داخل التطبيق وقواعد Firestore لعملية الربط؛ يوصى أيضًا بفرض Firebase App Check/Play Integrity قبل الإطلاق لمقاومة العملاء المعدلين، ولا يُدّعى أنه يحمي جهاز root حماية مطلقة.
- البحث يعرض حتى 200 طالب، والإيميل/الهاتف يبحثان على الخادم مباشرة. القوائم الأخرى محدودة 400 مستند؛ الأسئلة حتى 100 في الاختبار. يلزم pagination قبل إطلاق أكبر من الحدود.

## البناء والاختبار

من داخل `student_mobile_app` مع Flutter stable المتوافق مع Dart ^3.13:

```bash
cp .env.example .env
flutter pub get
flutter analyze --no-fatal-infos
flutter test
flutter build apk --debug
```

workflow `Sibawayh Flutter and Firebase` يبني APK تجريبيًا ويختبر قواعد Firestore في Emulator. إعدادات Firebase تمرر كمتغيرات موضحة في دليل الإعداد. لا تحتوي النسخة على حساب مالك أو كلمة مرور افتراضية. البناء debug وليس إصدار متجر موقعًا بمفتاح المالك.

قبل فتح المنصة للطلبة: تحقق من إعداد Firebase الحقيقي، واختبر APK على جهاز أندرويد مع السماعات وVPN/Proxy وملء الشاشة والخلفية ومصادر فيديو حقيقية.
